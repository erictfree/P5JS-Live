p5js.live

Make the code part of the performance.

Play audio-reactive p5.js visuals live in the browser.

Keep the canvas, sound analysis, clock, and working scene alive while you rewrite one visual idea at a time. Compose patches, map motion to sound or MIDI, process pixels with shaders, and perform with other browsers.

An open-source effort led by Eric Freeman in the Department of Arts and Entertainment Technologies at The University of Texas at Austin.

Edit the performance in place.

Change one idea without stopping everything else.

Put your cursor in a patch or scene and press Cmd/Ctrl+Enter. A successful edit joins the running composition at a frame boundary.

Syntax, evaluation, and first-frame failures leave the last working version on stage, so experimentation can remain part of the show.

function pulse({ time, audio }) {
  const size =
    80 +
    sin(time * 2) * 30 +
    audio.bass * 160;

  circle(width / 2, height / 2, size);
}

Use JavaScript as the instrument.

No proprietary visual language. No hidden composition graph.

Draw with familiar p5 calls such as circle(), fill(), and noise(). Package ideas as ordinary functions, objects, classes, factories, or closures. Keep the scene itself in a readable array.

p5js.live supplies the performance infrastructure while the important programming ideas stay visible and editable.

Give every patch a pulse.

One shared analysis turns a file, microphone, mixer, or audio interface into performance data:

  • overall level
  • bass, mid, and treble energy
  • onsets and automatic beat tracking
  • FFT spectrum data
  • waveform data

Drive motion directly from sound, tap in a tempo, or shape shared signals with LFOs, lag, envelopes, sequences, and MIDI controls.

The same patch can also animate in silence, so audio remains a material—not a requirement.

const size = 40 + audio.bass * 220;
const wobble = sin(time * 2 + audio.mid * 3);
const flash = audio.beat ? 255 : 30;

Compose small ideas into a set.

A patch is one visual behavior. A scene is an array that says what plays and in what order.

Nest arrays to create isolated render groups, then chain movement, opacity, feedback, and GPU effects onto exactly the group you mean.

The Scene inspector connects the running layers back to source, while reviewable tools can add, remove, and reorder scene entries without hiding the resulting code.

Keep favorite material in a patch library, install community patches as editable source, and reuse them across performances.

const scene = [
  solidBackground,
  [waveScope, laserFan]
    .rotate(0, 0.2)
    .opacity(0.8),
];

scene.draw();
const clubLens = new ShaderChain()
  .noiseWarp(({ audio }) =>
    0.005 + audio.bass * 0.03, 5, 0.1
  )
  .bloom(({ audio }) =>
    0.3 + audio.bass, 4, 0.5
  )
  .rgbSplit(({ audio }) =>
    1 + audio.treble * 12, 0
  )
  .blend("screen")
  .mix(0.75);

Treat every pixel as material.

Process a layer after p5 draws it: transform, blur, bloom, split color, mask, blend, or feed the previous frame back into the next.

Use one patch as an image map to distort another. Turn the syntax-colored live editor into a patch with codeView(), then transform your own source like any other image.

Effect parameters can follow time, sound, signals, or controls, and a custom WebGL patch can take the chain further.

Build one image from many browsers.

Run one patch or the complete editor without restarting the performance.

Version history

Safe state

Open source, so the instrument can keep changing.

p5js.live is for creative coders, visual artists, musicians, students, educators, shader authors, and VJs—anyone who wants to make the program itself part of the performance.

The project grew from an effort led by Eric Freeman in the Department of Arts and Entertainment Technologies at The University of Texas at Austin.

Open the instrument and change one number. If you know some JavaScript or p5.js, you already know enough to begin.
